# OncoKB v3.9 cancer genes

cancer genes list

## Usage

``` r
data(oncokb_genes)
```

## Format

A list

## Value

An object containing cancer-associated genes annotated by OncoKB.

## Examples

``` r
data(oncokb_genes)
length(oncokb_genes)
#> [1] 396
head(oncokb_genes)
#> [1] "AKT1" "ALK"  "APC"  "AR"   "ATM"  "BAP1"
```
