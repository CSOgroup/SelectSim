# Lung adenocarcinoma from TCGA cohort as SelectSim run results

Result of LUAD generated by SelectSim with SelectSim run done at
min.freq=10.

## Usage

``` r
data(luad_result)
```

## Format

A data frame

## Value

A data frame containing SelectSim results for the LUAD cohort.
